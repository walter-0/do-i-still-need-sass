Variables
Native
Widely available ·2019
CSS has CSS Custom Properties are more dynamic and can be updated at runtime.
Show Example
Sass
$primary-color: #3498db;
$padding: 16px;

.button {
  background-color: $primary-color;
  padding: $padding;
}
CSS
:root {
  --primary-color: #3498db;
  --padding: 16px;
}

.button {
  background-color: var(--primary-color);
  padding: var(--padding);
}

Operators
Partial
Widely available ·2018
CSS has calc() supports math operations, but Sass offers more comprehensive operators.
Show Example
Sass
$base-size: 16px;

.container {
  width: $base-size * 20;
  padding: $base-size / 2;
  margin: $base-size + 8px;
}
CSS
.container {
  width: calc(16px * 20);
  padding: calc(16px / 2);
  margin: calc(16px + 8px);
}
